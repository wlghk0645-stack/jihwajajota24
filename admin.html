클라우드 데이터베이스(Firebase) 연결 설정 필요

이 위젯을 깃허브 페이지 등 외부 환경에 배포하여 스마트폰과 실시간 연동하려면, 본인의 Firebase 설정값을 입력해주셔야 합니다. 아래 절차를 완료하시면 즉시 전 기기 연동이 활성화됩니다.

🛠️ 실시간 동기화 활성화 방법:

1. Firebase 콘솔에 접속하여 새 프로젝트를 생성합니다.

2. 빌드 메뉴에서 Firestore Database를 생성합니다. (보안 규칙은 테스트 모드로 시작 또는 읽기/쓰기 허용 설정)

3. 프로젝트 설정에서 웹 앱()을 추가한 후 발급받는 설정 객체(firebaseConfig)를 복사합니다.

4. admin.html 및 index.html 하단 스크립트 영역의 firebaseConfig 안에 해당 값들을 붙여넣고 깃허브에 다시 커밋하세요.
